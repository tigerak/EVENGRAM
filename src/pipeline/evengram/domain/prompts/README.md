## [v1.2] - 2026-02-24
### 🎯 개선 배경 (Why)
* **문제:** Layer 1 (법률 관계 레이어)가 과도하게 마이크로 시퀀싱 됨.
* **원인:** 이전 v1.1에서 Layer 2 (사실 관계 레이어)의 마이크로 시퀀싱을 위해 prompt 개선한 후 부작용.

### ✨ 업데이트 사항 (What's New)
* **[기능] Few-shot 예시 교체:** 단순한 문장 대신 전문 용어가 포함된 복합문 예시 3개를 추가하여 문맥 파악 능력 강화.
* **[지시문] Step-by-step 유도:** "먼저 명사를 추출하고, 그 다음 관계를 정의하라"는 식의 단계별 사고(CoT) 지침 명시.
* **[포맷] JSON 스키마 강제:** 출력값의 일관성을 위해 구체적인 JSON 필드 구조를 제안함.

### ⚠️ 여전히 부족한 점 (Shortcomings)
* **한계:** 500자 이상의 장문이 들어올 경우 여전히 관계가 누락되는 '중간 소실' 현상이 발생함.
* **부작용:** 지시문이 길어지면서 Flash 모델 기준 토큰 소모량이 약 15% 증가함.
* **다음 계획:** 다음 버전에서는 문장을 문단 단위로 쪼개서 처리하는 루틴을 프롬프트에 녹여볼 예정.
